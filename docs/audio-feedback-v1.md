# 操作音效 V1

沿用既有声音吸引僵尸机制，为玩家增加可播放的脚步、奔跑、门、近战挥击、枪声、受伤、物资取放与装卸弹短音。参数集中在`godot/data/audio.json`，原创确定性合成器位于`game_audio.gd`，无外部采样或新许可证依赖。

音频为22050Hz单声道16位PCM，启动时生成八段短音，复用八个播放器；不在每帧生成波形。振幅限制0.8，默认播放器音量-10dB，限制同时发声数量。静音键 **M**，当前仅会话有效，未新增设置存档。

脚步按照实际水平移动距离累计，不按按键判断，因此撞墙原地不会持续播放脚步。跑步步频随真实速度增加。受伤与物资操作读取新发生的真实事件；近战仅成功发起攻击时播放。新游戏/读档重置事件游标，历史日志不会重复播放。音效不写入噪声状态，静音也不会削弱既有奔跑/战斗对僵尸的吸引。

## 验证

`test_game_audio.gd`在实际Godot场景中执行移动、跑步、开门、进屋搜刮、近战、受伤和保存继续；受伤为明确测试夹具。检查波形可重放生成、有效非零PCM、峰值范围、固定播放器池、事件触发、历史不重播、静音与AI噪声独立。额外直接播放枪声用于验证静音和恢复，不将其宣称为真实射击测试；真实射击仍由原枪械试玩回归覆盖。

```powershell
python tools/run_checks.py --godot D:\GameDev\Godot_v4.7.2-stable_win64.exe --visual
```

单项真实渲染日志为`work/visual-slice/audio-check.log`，结果`GAME_AUDIO_OK`；完整回归为`audio-full-checks.log`，结果`ALL_CHECKS_OK`，既有生产存档/导出指纹不变。测试使用隔离存档目录，无新存档字段。本轮没有修改Blender资产，执行Godot导入和完整规则/实机回归，没有重复生成源模型；前一轮Blender字节一致重放记录仍保留在`full-checks.log`。

## 限制

这是第一轮操作反馈，不是最终音效设计。尚无立体定位、墙体声学遮挡、室内混响、脚下材质区分、僵尸嘶吼、环境氛围、背景音乐或完整混音设置。合成枪声与门声仅作为功能反馈，不能声称具有真实录音的音色。已验证引擎音频流和播放调用；用户设备扬声器输出及主观听感仍需人工试听。没有新增或改变噪声半径、战斗数值、库存、模型和地图。
