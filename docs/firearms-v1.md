# 手枪与有限弹药 V1

本轮在美术材质/灯光提交 `101d372` 后进入玩法。实现首个可玩的枪弹闭环；仍保留独立开发分支，不推送或合并。用户已允许后续复用资产扩充房屋街道，并要求参考定妆照丰富僵尸外观；本轮尚未扩图或完成僵尸分型。

## 实际玩法

- 新游戏中，杂货店现有物资容器增加一把空手枪、18发9毫米弹药。不是起始赠送，也不是无限弹药解锁。
- 进入杂货店，靠近物资按 **B** 打开存取面板，逐件取出手枪和弹药。背包承重仍为5kg；**E** 仍是按承重尽量搜刮，食物/水可能先占满背包。
- **5** 装备手枪；**F** 装填，需2秒有效游戏时间。弹匣6发，支持不足6发的部分装填。背包打开时游戏暂停，关闭后继续装填。
- **空格** 朝人物当前面向射击；WASD调整位置与朝向。每发扣1发，0.4秒射击间隔；弹匣空或正在装填时不能射击。换枪会取消正在进行的装填，但不会吞掉弹药。
- **U** 将弹匣内弹药退回背包。存入手枪前须先卸弹，防止当前简化弹匣模型产生隐藏装弹或转存复制问题。
- 手枪0.85kg、每发弹药0.012kg，装入弹匣仍计入负重；装填/卸弹不改变总重量。
- 枪声使用32米声音事件，沿用墙体声音衰减及僵尸感知。射击最多伤到正前方4度范围内最近的一只目标，14米规则射程，伤害38；墙体和关闭的门阻挡。上述是游戏平衡初值，不是现实枪械参数。
- 实机有独立持枪网格、单手持枪姿态、短时弹道反馈与库存数字；命中沿用受伤、死亡和日志规则。枪声目前是AI可感知的机制事件，尚无可听音频。

## 保存和旧存档

规则位于 `godot/data/rules.json`，弹药账本/装填位于 `scripts/firearms.gd`，权威库存及校验仍在 `survival.gd`。

快照保存 `firearms.loaded` 和 `firearms.reload_left`，以及原有背包、容器余量、门、僵尸和事件。旧schema1–4快照可不含此字段，恢复时仅在内存补零值，不修改原文件、不填充已生成容器。因此旧局若没有枪弹，需新游戏体验本轮新增物资；没有通过读档补货。

日志记录装填、卸弹、射击消耗及击倒。非法装弹量、负计时、没有枪却有装弹、超出负重等状态会被拒绝。现阶段只有一种手枪、一种匹配弹药、单个玩家弹匣账本；未做多把枪的独立序号、可交换弹匣、卡壳、枪械耐久、瞄准技能或掉落系统。

杂货店18发全部耗尽后，该容器不会再生弹药。后续东侧住宅扩充已加入另一处12发的有限来源，见 `east-block-v1.md`；新增地点通过独立世界修订加入，原杂货店不补货。所有地点都搜空后应改用近战，不能用反复读档刷新代替探索。

## 验证与实机证据

- `test_firearms.gd`：实际有限库存取枪取弹、空枪/冷却/装填阻止射击、部分装填、卸弹守恒、装弹重量、装填中存读档、打空再取剩余弹药、非法快照、旧档无补货。
- `test_firearm_playthrough.gd`：实际键盘移动进杂货店、存取面板拿枪弹、装备和实时等待装填、保存读取、开关门、墙体挡弹、枪声被AI听到、最近目标单发伤害。导航阶段无敌人；战斗阶段显式生成两个受控目标，伤害断言时冻结目标位置。这不是一段未经干预的自然遭遇录像。
- 截图 `work/visual-slice/firearm-01-found.png` 至 `firearm-04-street-shot.png` 来自运行中的Godot场景，固定1920×1080视口。枪械造型、瞄准/换弹动作目前属于功能原型，未宣称通过产品级人物动作美术验收。
- 上述测试已加入 `tools/run_checks.py`；全套回归检查仍保护原存档/日志导出指纹。原始记录见 `full-checks.log`、`firearms-rules.log`、`firearms-playthrough.log`。
