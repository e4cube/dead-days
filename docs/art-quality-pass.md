# 人物与陈设结构质量首轮

本轮根据用户提供的《僵尸毁灭工程》《生存日志》截图，调整原创美术取向：生活化比例、可信旧家具与物资形态，结合更清楚的室内层次与冷暖照明。保留已确认的室外等距/室内近颈后镜头，不复制参考作品模型、贴图、地图或UI。

此前资源主要是机制占位，不能把“能看出是什么”当成美术完成。本轮只完成以下结构修订，不宣称达到参考图质量。

## 实际模型修改

- 玩家：头部缩窄，重新制作平滑头颅与后颈发际线、分色发片及发束；替换方块躯干为有肩宽/收腰的环形截面，袖子、四肢、手和耳朵采用曲面，适当重叠关节端部。衣物改为较克制的灰绿，背包采用圆角布包，肩带是从胸前经过肩头到背包的连续厚带。仍为原16骨骼、2网格及6个动作，刚性分段蒙皮尚未改为连续柔性关节。
- 柜子：改为侧板、顶底横板、背板和有凹进层次的门板组合，共1124三角面/11网格，保留原体积及简化碰撞；没有新增开柜门动画。
- 住宅：沙发和靠垫增加多段圆角；厨房工作台按水槽开口拆成四块，水槽为带盆沿、内壁和盆底的凹形几何。现在155个布局模块，原8个家具碰撞及通路不变，没有水流或新烹饪功能。
- 杂货店：罐头由方块改为圆柱，水瓶分为圆柱瓶身、窄瓶颈和瓶盖；共123个模块，所有瓶部件随真实库存同步收起，避免搜空后残留悬空瓶盖。货架库存和存取规则不变。

源工程与GLB都已重新生成，共21类资源。玩家6318三角面，近景预算提高到8000；其他原始资产仍限制2000。僵尸仍为上一轮1152三角面，未声称本轮已重做全部人物。

## 生产与验证

重建依次运行 `tools/generate_assets.py`、`generate_house_details.py`、`generate_shop_details.py`（Blender后台）；启动与完整测试命令沿用 [资源管线](assets.md)。

曲面模型暴露出导出重复性问题：Blender进程间会改变部分平滑面三角列表顺序，个别法线分量有约4e-5差异。导出对玩家的不透明三角索引稳定排序，并对法线按0.01分量网格量化后重新归一化；不修改顶点位置、朝向、权重或动画。严格GLB字节重放检查继续保留，没有放宽为近似比较。源工程保留完整几何，导出法线量化仅影响微小着色细节。

完整日志 `work/quality-final-checks.log`，实景图 `work/house-interior.png`、`shop-stocked.png`、`c3-poses.png`。近景截图展示实际游戏，动作图为实际骨骼采样，不是生成图片。回归继续覆盖21份GLB重放、角色蒙皮/六动作、室内实体镜头、家具通行、物资存取/读档、追击脱离、真实跨日休息；生产存档/导出由指纹保护。
