# 室内近颈后跟随镜头

本轮按用户确认改变室内镜头方向：室外仍是等距正交视角，进入住宅、诊所或杂货店后自动切到透视肩后跟随视角，保留实体屋顶、外墙和房间隔墙。正式游戏不再使用室内剖切或树冠隐藏；此前有关自动隐藏屋顶和房屋整体构图的报告是旧版记录。

镜头默认目标距离从首次跟随版本的2.6米缩短为0.55米，并偏向人物右后方，前方留出视线。滚轮可在0.35–1.8米调整，独立于室外缩放。人物转向时镜头跟随，Q/V可按45度环视；出屋恢复原等距视角及室外缩放。进出采用视角切换，尚未制作镜头切换淡入淡出。

## 操作

- 室外：WASD仍按世界方向移动，Shift跑步。
- 室内：W/S前后移动，A/D原地转向，Shift配合前后移动跑步。原地转向不制造跑步声音或消耗跑步体力。
- Q/V环视、滚轮调距、E交互、B存取、L照明、I背包、J日志等保留。

相机以人物后脑和颈部为目标，肩部偏移和镜头臂分别用五条带间距的物理射线检测，碰到墙、门或家具则缩短距离，不穿过不透明障碍。极窄位置会临时隐藏过近的人物网格，避免头部填满镜头；角色本身、碰撞、AI和存档状态仍存在。这是有限半径的射线探测方案，不是完整球形扫掠相机，尚无鼠标自由环视、俯仰和手柄控制。
