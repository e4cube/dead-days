# 门耐久与入口失守 V1

关闭房门仍阻挡视线、角色碰撞和导航。僵尸在追击/搜索期间，如果最后看到或听到的目标位于门的另一侧，会寻找正门；靠近后使用原有攻击前摇与冷却撞门。它不读取隐藏玩家的新位置来决定撞哪扇门，失去记忆后仍回到游荡。

## 规则与持久化

集中配置`rules.json/door_damage`：门耐久120、每次撞击12、有效距离1.1米。十次有效撞击才破门，多只僵尸可累计伤害。保留原有6秒搜索记忆，保持安静能让单次追击结束；反复制造声响会使搜索持续，受损门不会自动恢复。

`door_damage.gd`管理耐久、损坏与校验；`zombie.gd`使用记忆目标调查入口，`game.gd`更新实际碰撞和寻路。门破坏后，门板倒落，关闭位置和打开位置的碰撞均移除，重建导航；不能再按E关闭。床仍要求可关闭的房门及无危险环境，损坏入口不能当作安全休息点。

耐久字段`door_health`随世界存档保存；旧档没有此字段时在内存初始化，各建筑既有开关状态保持。当前损坏门必须为开放状态，负耐久、超上限或不匹配门ID被拒绝。不会修改旧快照、补物资或复活僵尸。旧存档扩充新街区后，只为新增门补初始耐久。

靠近门显示耐久，撞击与破坏写入真实日志并触发已有门音效。当前撞门音效不生成额外AI噪声事件，以免僵尸互相维持无限搜索；玩家的跑步、门操作和战斗噪声规则继续生效。

## 验证与限制

`test_door_damage.gd`验证伤害、开门不受撞击、旧档迁移、非法状态拒绝、受损存读档与损坏门不能关闭。实机路线通过实际输入进屋关门后，设置明确夹具：一只门外僵尸、记忆目标位于室内、门预先削弱至24耐久。随后使用正式AI前摇、冷却、碰撞和导航，验证先挡住、受击存档、破门、实际穿过入口和损坏状态读取。这不是自然遭遇证明，也不是默认门两击即坏。

四张1920×1080实机截图为`work/visual-slice/door-01-bashing.png`、`door-02-breached.png`、`door-03-clear-entry.png`、`door-04-retreat.png`；条件在`door-capture-conditions.json`。后两张通过实际攻击输入，用搜到的木棍击杀入口僵尸，再移动至室外；不声称徒手绕过活僵尸成功。单项日志`door-check.log`，完整回归`door-full-checks.log`。

`test_door_attack_intent.gd`补充验证攻击前摇的门目标可保存：中途开门不会将撞门攻击无条件转移到玩家，重新读取前摇只结算一次门伤害，游荡与记忆失效不撞门。受击朝向和门板晃动已接入；破坏后复用原GLB门板倒落，读档直接恢复倒落姿态。不是碎片破裂模型。

第一次完整回归发现街区扩充测试的“历史存档”夹具仍携带新建模型的四扇门耐久，却只删除了新增门开关，产生孤立字段并导致测试后续访问空状态。修正夹具使其真正不含历史上不存在的耐久字段；保留生产存档的严格校验，没有放宽异常状态检查。
