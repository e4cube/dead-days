# 三栋建筑独立照明

住宅沿用原有暖灯；诊所和杂货店新增独立室内灯。进入对应建筑按L切换，底部上下文提示显示当前开/关，真实开关行为写入日志。两栋商用建筑初始关灯，住宅保持原先默认开灯。

新增灯的颜色、位置、功率和距离集中于 `godot/data/interior_lights.json`。诊所采用较中性的浅冷光，杂货店采用暖光；两盏局部光关闭动态阴影，住宅原灯保留原设置。墙灯几何为Godot简单灯壳，不增加新Blender资源，现有21套源工程/GLB继续复用。灯壳随支撑后墙剖切隐藏，关灯不删除灯壳。

## 存档兼容

住宅继续读写可选布尔值 `house_light`；诊所/杂货店采用可选 `building_lights` 字典，缺失字段默认关灯，不重写旧快照。校验拒绝非字典、非布尔值与未知建筑键，保存格式继续为schema4。开关操作集中在生存模型，死亡/睡眠期间禁止切换，渲染仅反映模型状态。

## 验证

新增 `test_interior_lights.gd`：采用明确的22:00及无僵尸出生夹具，以真实移动从出生点走进诊所、开灯、保存继续、关灯，再走到杂货店重复验证，检查两栋建筑的状态互不影响。测试同时核对旧快照字节不变和非法字段拒绝。截图是实际Godot渲染的夜景夹具，不冒充从白天玩到夜晚；真实跨日与敌人感知继续由原有专用测试覆盖。

完整测试命令沿用 [诊所切片](clinic-art-slice.md)，日志 `work/lights-final-checks.log`；截图为 `work/clinic-night-lit.png`、`clinic-night-dark.png`、`shop-night-lit.png`、`shop-night-dark.png`。

启动仍使用Godot打开 `godot/project.godot`，进建筑后按L即可。未实现电网、燃料、电力消耗、灯光吸引僵尸或断电；无阴影局部光可能透过薄墙，不代表已完成光照遮蔽或最终性能验收。
