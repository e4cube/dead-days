本文件随当前验证更新。分支 `feature/dead-days-visual-slice-v1`，基线 `076dc3241afb315ed3e9521acdfe4935908926f7`；初始工作区干净，本地与GitHub重构分支一致。未合并main、未推送本切片。

## 范围与用户后续确认

后续用户已明确允许推进玩法、复用资产扩充房屋街道及僵尸分型。因此下文最初“不扩图/不新增玩法”的约束仅描述初始切片；当前保留原三栋位置，新增东侧住宅，详见 `east-block-v1.md`。原始基线与扩充后的场景内容不同，原机位截图仍可观察材质变化，但不能用作完全相同负载的性能对照。

美术目标保持 Grounded Stylized Realism，参考10张原图及新增AI定妆照，以独立辨识度和可玩性为先，不追求AAA工艺，不改街道排列或新增玩法。用户在2026-10-24指出头颈比例问题后，最终确认撤销近颈视角：室内外统一正交斜俯视，进屋剖顶与近侧墙，出屋恢复。默认主入口与 `godot/visual_slice_v1.tscn` 都使用该相机，后者单独应用切片日夜曝光参数。旧近颈实现保留为非默认历史模式。

- 东侧街区V1：数据化边界和世界修订号，新增一栋共享源资产但具有独立库存/门/灯/床的住宅；旧快照只在内存加入新增地点，旧物资、枪弹及敌人状态保持。完整流程、范围和限制见 `east-block-v1.md`。新增五张东侧实机图的条件独立记录，不混入原路线或自然追击证据。

- 僵尸外观分型：普通/工人/警员共享主体、16骨骼与五动作，通过可显隐服装和帽型区分；稳定外观ID进入存档，旧档默认为普通并保留死亡等世界状态。新增背心/帽材质仍使用原始表面生成管线，详见 `zombie-appearances-v1.md`。`zombie-appearances.png` 为真实游戏街道的暂停排列展示，隐藏玩家/HUD，不冒充自然遭遇；正式连续试玩另行验证。女性、肥胖体型、差异AI与职业掉落未实现。

- 用户在材质阶段后授权继续玩法，并允许后续复用资产扩图及僵尸外观分型。首个接续玩法是有限枪弹系统，源工程玩家GLB增加可独立显隐的持枪网格，具体规则、操作、兼容与验证见 `firearms-v1.md`。原视觉切片截图保持同机位；四张新增枪械图为受控玩法实机测试，另有 `firearms-capture-conditions.json`，不冒充自然遭遇。扩图和僵尸分型尚未完成。

- 木材与室内灯校准：旧木/浅木纹理周期0.5→0.32米，新增配方级可选 `normal_strength`，两种木材为0.18，其余继续用共享默认0.35。Blender节点与Godot运行时同读此参数，重导源工程与GLB，未引入第二套材质库。住宅灯能量1.2→0.65，开关/保存逻辑不变。当前柜面纹样更细、凹凸更克制，但木纹仍重复；剖顶隐藏屋顶会改变室内日光遮挡，尚未完成保留屋顶阴影的独立渲染处理。

- 住宅外立面与道路边界增量：住宅增加实体窗框、窗中梃、门套、两侧檐口和排水槽；构件使用 `DD_Hide_Front/West/East` 命名接入既有视向剖切。原门窗位置和玩法碰撞不变，窗户仍为原有墙面玻璃表现，不是假称已完成真实窗洞或可翻窗系统。住宅从988增至1736三角面，未放宽2000面预算。墙脚使用 `foundation → concrete` 集中别名，去掉住宅底部金属块观感。道路52段矩形泥土边条改为不规则六边形，实例位置不变、无新增碰撞；草地边界仍有规则化重复和材质混合不足。实机近景、日夜及连续进出流程截图已更新。

- 室外植被增量：六个树冠节点内改用288个圆边折面叶簇，摆脱实心球团，保留可见分枝、原树干与原树冠隐藏节点名。使用现有共享 `foliage` 配方，不增加透明纹理或外部资源；叶簇正反面显式建面，面数高于旧实心冠，需结合实际性能看待。草丛改为30根带中段弯折的窄草叶（300三角面），仍通过原MultiMesh放置、关闭草影及45米距离裁剪；没有增加实例数或改变通行。第一版尖叶在实机中呈刺球感，已缩小叶片并改为圆边；当前仍有纸片层次、树形重复，尚未达到参考植物的自然程度。固定机位日夜与进屋截图已重采。

- 沙发软垫增量：坐垫厚度由8厘米调整为16厘米，增加两块独立圆角靠垫；不扩大原沙发占地，不改碰撞。住宅现174个视觉模块；实机截图可见坐垫、靠垫与框架之间的结构层次，但仍缺少自然褶皱、缝线和旧化。没有因此宣称达到参考图最终品质。

## 生成与导入中修复的问题

增加UV后，Blender glTF导出出现约1e-7的浮点抖动，导致GLB字节回放不一致。生成前米制UV取整，导出后仅将UV规范到1e-4网格并稳定半格边界，512px下误差小于约0.027像素；没有改碰撞、蒙皮、动画或放宽哈希检查。原有角色法线/三角顺序规范化保留。

Godot默认会将内嵌图像抽出到资源目录，本轮改用压缩内嵌导入，避免大量重复源PNG进入正式目录。实现依据[Godot官方导入器选项](https://github.com/godotengine/godot/blob/master/modules/gltf/editor/editor_scene_importer_gltf.cpp)。切换产生过旧缓存UID引用错误；只将自动生成缓存与本轮新建的抽出图像备份到忽略目录后重导入，没有删除既有资产或存档。

本轮没有烘焙几何AO，没有完成全资产旧化遮罩，也没有把概念图精度当成验收结果。人物增量已将袖管、裤腿接成连续蒙皮，僵尸破袖/膝部采用同一表面的材质区域；仍未达到自然衣褶与人体精修标准。后续优先：家具结构与生活痕迹→人物头发、服装与手部轮廓→树冠/路面边界与磨损遮罩→静态材质/网格合批和更长性能采样。保持现有地图、最终正交相机约定和玩法，不以新增资产数量代替质量。

早期回归中的跨建筑测试依赖固定帧数，在一次冷导入后没有准确停在诊所门口。现改为读取实际物理位置、持续发送同样键盘输入的航点反馈；没有瞬移或移除障碍，超时仍失败。完整流程中的遇敌检查也改为实际跑步发声后等待僵尸感知，避免仅凭“场景里存在僵尸”算验收。
