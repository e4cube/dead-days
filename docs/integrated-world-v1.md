# East Expanse V1：原街区 + District 07 + Halvorsen 工厂

新增一个独立但连通的场景，把原版灰湾街区、北区/田径场/市集/别墅，以及废弃工厂接成一张可步行地图。原版主场景、`game.gd`、`rules.json`、存档和既有测试都不改动；这个场景通过继承 `game.gd` 追加东侧扩展。

## 启动

```powershell
& 'D:\GameDev\Godot_v4.7.2-stable_win64.exe' --path 'D:\GitHub\dead-days\godot' res://locations/integrated_world.tscn
```

进入菜单后选择“新游戏”，从原街区住宅前开始。沿主街向东走到东端，经联络路进入 District 07；再穿过街区东门，沿联络路到 Halvorsen 工厂大门。

## 连通布局

| 区域 | 世界位置/范围 | 连接方式 |
| --- | --- | --- |
| 原版街区 | `x -13.5 … 34.5` | 东端旧边界移除，接 7 m 联络路 |
| District 07 | 中心 `(90, 0, -22.5)` | 西侧新开车行门洞，主街与原街同高 |
| 田径场 | `(90, 0, -47.5)` | 街区内中央步行道直达南门 |
| 市集 | `(67, 0, -14.5)` | 街区主街南侧，开放式摊位空间 |

| Halvorsen 工厂 | 中心 `(165.5, 0, 22)` | 街区东门 → 北侧联络路 → 厂区南门 |
| 工厂内部 | `x 152.95 … 178.05`，`z 15.25 … 29.45` | 大门进入，屋顶/南墙/东墙剖切 |

- 新增扩展地面、联络道路和远处背景地面，避免原街区东端出现悬空；
- 原版东边界已移除，但远端仍保留新的世界边界；
- 僵尸导航网格从原街区扩展到整张地图（280 × 168 个 0.75 m 单元），并把新模块的墙体/家具加入障碍源，现有僵尸可以沿道路追到新街区与工厂；
- 工厂位置按它真实的局部坐标放置：大门 `z=-19`，所以世界中心在 `z=22`，入口正好落在 `z≈3` 的联络路上；
- 街区东西墙各开一个 10 m 门洞，带门柱和过梁。

## 二层别墅

- 别墅从单层改为两层；两层楼的墙体、屋顶、前墙、东墙、二层楼板/栏杆分开；
- 一层：客厅、厨房、餐区、卧室、卫生间式内隔墙、泳池庭院；
- 二层：开放 Loft、双人床、衣柜、书桌、书架、休闲椅、地毯、绿植、玻璃栏板；
- 进入别墅自动剖切屋顶/前墙/东墙；
- 站在一层时二层组隐藏，相机聚焦一层；沿西侧楼梯走上去，二层组显示、相机抬升；沿楼梯走下来恢复；
- 楼梯有**连续斜面碰撞**，视觉上是逐级台阶，角色可以直接走上去，不需要按 `E`；
- 二层床边按 `R` 短休、`T` 睡到黎明，已接入 `Rest` 系统。

三个新区域都接入原有 `model.loot()`、负重、背包和存档，按 `E` 搜刮，物品会真实进入背包，容器剩余量会写入存档。

| --- | --- | --- |
| 别墅一层 | 冰箱 | 食物 ×2、水 ×2 |
| 别墅一层 | 厨房柜 | 食物、水、绷带 |
| 别墅一层 | 床头柜 | 绷带、9mm 弹药 |
| 别墅一层 | 衣柜 | 木棍、9mm 弹药 |

| 市集店铺 | 店铺柜台 | 食物、水、绷带、9mm 弹药 |
| 市集 | 果蔬摊 | 食物 ×4、水 ×2 |
| 市集 | 杂货摊 | 食物、水、绷带 |

市集本身是开放空间，没有门禁；摊位就是它的“可进入”部分。工厂进入后自动剖切屋顶、南墙和东墙。

## 已知限制

- 导航网格已扩展到整张地图，现有僵尸可以沿道路追到 District 07 和工厂；没有额外新增僵尸出生点。
- 新搜刮点用 `E` 直接搜刮，不打开新的独立储物面板；储物面板仍只服务原版建筑内的柜子。
- 别墅二层是连续斜面碰撞上的视觉台阶，可以直接走上去；工厂夹层仍未接入导航。
- 市集后方是三间开放前脸店铺，可以直接走入；没有可关的门或完整室内屋顶。
- 这是独立连片场景，不替换 `main.tscn`，也不改变原版街区的存档起点。
- 截图在 `work/integrated/`；`work/` 被 `.gitignore` 忽略，提交截图需 `git add -f`。
