# Dead Days 美术标准 V1

## 定位与基线

Grounded Stylized Realism — 写实比例的等距三维末日生存。低面数是优化方法，不允许用方块、球状树冠、僵硬关节代替经过设计的形体。参考用于比例、空间和光影研究，不复制具体美术资产。

审计基线：`feature/dead-days-rebuild`，提交 `076dc3241afb315ed3e9521acdfe4935908926f7`。开始时工作区干净，GitHub 分支 SHA 相同。独立交付分支为 `feature/dead-days-visual-slice-v1`；不合并 main，不自动推送。现有 Python/Pygame 保留为 legacy，实际引擎是 Godot 4，Blender 后台脚本生成源工程与 GLB。

## 镜头与比例

最终镜头确认（2026-10-24）：用户指出近颈视角下头部比例怪异，明确撤销近颈跟随要求，改用《生存日志》《僵尸毁灭工程》那种进屋剖顶的斜俯视镜头。室外与室内统一三分之四正交，偏移 `(11,15,14)`、45°旋转。进屋隐藏屋顶和面向镜头的高墙，保留低墙与真实家具；出屋恢复。室内焦点以房间中心为主、30%跟随玩家，缩放为室外尺寸的0.65倍并限制在8.5–17.5。WASD仍是世界方向移动，Q/V旋转、滚轮缩放。测试基准1920×1080，固定时间和路径；角色特写在室外缩小正交尺寸。剖切只改可见性，绝不删除碰撞、门、导航或家具。早期近颈镜头记录仅供历史对照，不再是默认行为。

新增 `user-character-sheet.png` 是用户确认的AI定妆参考：幸存者深色头发、橄榄夹克、棕色帆布包、深灰裤与实用靴；僵尸灰败皮肤、褪色破损衣物、前倾和不对称姿态。重点是独立辨识度，不追求AAA工艺，不改变现有街道排列。美术目标仍为写实比例与末日氛围；此图不冒充实机画面、不直接做贴图。

单位1m；成人约1.75–1.85m，头高约0.23–0.26m，门净宽至少0.9m、高约2.05m。家具必须有结构：桌高0.72–0.78m，座高0.42–0.48m，床长约2m，厨房台面约0.9m。车轮接地、轴距与车身匹配。建筑墙厚0.12–0.25m、真实窗框、屋檐和门洞。树干、分枝和叶簇须有层次；地面路缘、修补和裂缝必须有结构方向与成因。

## 资产制作标准

人物与僵尸保留16骨架及已有动作契约。先改人体与服装轮廓、颈肩、手脚及关节连续性，再加局部细节；僵尸使用独立姿态、破损衣缘与色调，不仅给玩家换绿皮。家具包含支撑、板厚、接缝、门板或软垫；汽车包含引擎盖、挡风玻璃倾角、车顶过渡、轮眉、灯与轮毂。倒角宽度按真实尺度，硬边控制不能全靠平滑法线。所有资产保持现有碰撞占地与通路，必要改动必须同步导航并回归。

## PBR 配方与集中配置

唯一基准为 `godot/data/material_library_v1.json`。每项包含ID、sRGB颜色、粗糙度、金属度、类别和米制纹理尺度；共享可选贴图路径模板、变体规则、来源和授权。`aliases`兼容旧Blender命名，`house_aliases`兼容住宅表面；Blender将无贴图颜色转线性写入glTF，Godot使用sRGB颜色接口，禁止重复转换。使用已着色Base Color贴图时颜色因子为白色。`tools/generate_surface_maps.py`生成原始512px结构研究贴图：木纹/节疤、路面集料与裂纹、墙面细孔/流痕、金属拉丝、织物组织；并输出粗糙度与由高度导出的法线。不是扫描材质，也不是完整旧化完成标记。AO暂未烘焙。

Blender保留源节点与米制按主轴投影UV，并将贴图打包进源工程/GLB；Godot共享StandardMaterial3D使用同一组贴图与参数、本地米制三平面投影以避免旧模型UV拉伸。法线强度0.35，两端投影方式不同，接缝和朝向仍须实机检查；不得声称逐像素一致。旧住宅程序噪声Shader保留为历史实现，切片住宅表面已使用共享PBR库。

Base Color不烘焙主光/投影；Normal使用切线空间，Godot导入后检查方向；Roughness/AO为线性数据。AO只表达近接遮蔽，不把整片阴影画死。主要共享贴图512–1024，近景主角最多2048，单套1024 RGBA约4MiB未压缩，复用优先。湿润变体降低粗糙度并适量压暗，不能无条件给所有表面加镜面。破损需要配合几何，不能仅换色。程序纹理必须有结构意义；简单重复噪声不通过最终门禁。

## 灯光与性能预算

日间使用单个有阴影方向光、低饱和暖主光与偏冷环境填充；黄昏降低高度、形成长影；夜间低环境亮度，路灯与住宅灯形成局部光池，室内灯遵循原有可操作开关。禁止曝光掩盖材质问题。Compatibility为最低兼容路径；不强开SSAO、SSIL、体积雾或多盏实时阴影灯。接触关系由几何落地、方向阴影和克制AO共同完成。

初始预算：玩家≤8000三角，僵尸待校准≤8000，车辆≤5000，单家具≤2000（整套住宅单独预算），共享材质优先；草使用现有MultiMesh，灯距离裁剪。预算是上限而非质量依据。1080p帧率须实测并记录GPU、渲染器、同步模式、预热与采样区间；不以编辑器或headless速度替代游戏FPS。

## 可重复生产与质量门禁

Blender5.2.2 LTS后台生成 `.blend` 与显式GLB；Godot4.7.2 Compatibility实际导入。坐标Blender Z-up导出Godot Y-up，地面原点、米制、不嵌入权威碰撞。生成脚本支持仓库内隔离output-root；重跑对比GLB和清单，禁止删存档解决测试。

每个街道/住宅/角色/车辆分别检查：几何轮廓与比例；材质差异和尺度；光影方向与接触；密度、色彩和纵深；实机可玩。任一未达标标为待改进。当前基线的方块僵尸、盒形汽车、树冠球簇、未烘焙PBR细节均不能因测试通过而宣称产品级。

实机验收：街道→住宅→E开门→进入→观察家具→E搜刮→离开→遇敌；四张固定条件截图加有序操作截图。实际库存、门、灯、时间、存档/读档、战斗、导航和动画必须回归。概念图、独立模型预览不算实机截图。
