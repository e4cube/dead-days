# 东侧住宅与街区扩充 V1

在用户允许扩充房屋街道后，沿原街道向东增加7米范围，新增一栋可进入住宅。保留原三栋建筑的位置、布局和库存ID；不是整座城市，也不是120米大地图。

## 可以实际游玩的内容

- 世界边界从X[-13.5,13.5]扩为[-13.5,20.5]，Z仍为[-10.5,8.5]，约34×19米。道路、人行道、路缘、泥土边界和导航网格延伸；原区域仍有地面与边界。
- 东侧住宅 `east_home` 的门口在X=14，位于杂货店东侧。复用 `building_home.glb`、`house_details.glb` 及床、柜等现有资产，没有复制整套模型文件。
- 包含与原住宅相同的卧室、厨房和客厅结构，有独立门、柜子、冰箱、床、灯光及容器交互碰撞。
- 柜子初始有罐头1、绷带1、9毫米弹药12；冰箱有罐头1、水1。搜刮与存取受原负重规则限制，物资有限且不刷新。这一栋没有额外手枪。
- 可正常进屋剖顶、旋转和缩放，L开关灯，B存取；关门并靠近卧室侧通道的床后可R休息。原有危险打断仍适用。
- 保存退出再继续，位置、库存、门、灯与时间都保留，旧住宅不会被同名库存覆盖。

## 最小架构调整

- `rules.json` 集中维护 `world_bounds` 与 `world_revision=1`；导航网格扩为67×37。地面、道路和边界由同一边界配置构建。街道Blender生成器也读该配置，不另写一套地面宽度。
- 建筑声明 `interior: house`，由住宅构建器按建筑ID实例化。`house_instances` 和 `house_lamps` 分别登记详情与灯；原 `house_details`、`HouseLamp` 等旧测试入口保留。
- 新碰撞名携带建筑ID，冰箱交互锚点不再都指向原住宅。不会再次生成原住宅负责放置的18棵树。
- 室内检测、镜头、剖切、灯光开关与灯状态校验扫描当前建筑配置，不再仅枚举固定三栋。
- 本次仍是同一朝向、沿X排列的房屋复用。任意旋转、跨街对门、多层、建筑尺寸变化以及所有店铺模板的通用注册尚未完成。后续不能仅改坐标就宣称支持任意城市布局。

## 旧存档安全

存档的游戏schema仍为4；世界内容另用 `world_revision` 演进，避免每次加地点都混入玩法schema迁移。

旧快照没有世界修订号时按0解释；允许其缺少 `introduced_revision:1` 的新地点。加载后只在内存补新增地点的门和有限容器，把修订号升为1，记录世界扩充事件。原有门、物资、弹匣、装填进度、僵尸外观与死亡状态保持原值，旧文件字节不改。

修订号1的快照若缺失新增门或容器会被拒绝，不能通过损坏当前快照自动重新填货。新增地点搜空并保存后，继续读档保持搜空。未知未来世界修订号拒绝加载。

若旧角色位置真正落入新增实体内部，场景构建仍沿用附近可通行点修正，并在需要移动玩家时记录陈设调整事件；这只影响内存，不改旧快照。迁移层不随机重置位置，正常接触家具边缘也不应触发修正。

## 实测与证据

- `test_world_expansion.gd`：真实旧快照文件迁移、旧库存/弹药/敌人不变、原文件字节不变、新区初始化、搜空保存读档无补货、缺字段和未来版本拒绝。
- `test_east_block.gd`：用键盘输入从原出生点走过旧边界、开门入室、搜刮弹药、灯光独立、存取独立、继续读档仍在新区、关门穿过侧通道去床边休息、离开恢复屋顶。导航路径能连接新增室内；新冰箱有独立碰撞锚点。
- 五张有序实机截图位于 `work/visual-slice/east-01-street.png` 至 `east-05-leave.png`；条件在 `east-capture-conditions.json`。测试关掉敌人出生以隔离几何与交互，玩家无瞬移、未赋值时钟；不冒充有敌人追击的自然遭遇。危险与枪械回归仍由独立测试覆盖。
- 地面图回归从旧的27米固定宽度断言改为配置边界、原区域及东侧覆盖检查，不放宽原素材来源与投影检查。
- 夜间存读档回归发现，沙发边缘约0.06毫米的接触误差会触发旧安全位置修正并挪动人物。安全位置检查现按胶囊水平圆形与矩形最近点计算，并容忍1毫米接触误差；真实穿入仍移至可走网格。新增 `test_restore_positions.gd` 验证角落、接触、真实穿入和已打开门，整夜睡眠中保存/继续的精确状态检查保留。
- 新区已有一次输入驱动试玩，但新区峰值帧率、更多建筑数量和长时间平衡未单独测量。V1性能采样仍为原住宅外静止、3只活僵尸，不作为所有新增区域的帧率保证。
