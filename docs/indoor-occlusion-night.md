# 室内前景植被与夜间验证

在住宅镜头基础上，新增相机方向相关的树冠遮挡处理。生成树木时缓存每个树冠的世界包围球；进屋后将房屋占地和树冠投影到屏幕，仅隐藏处于住宅中心前方且投影重叠的树冠。远侧植被继续显示，树干、枝干和实体碰撞保留；出屋恢复全部树冠。实现位于 `house_slice.gd`，由现有镜头/墙体剖切更新调用。

该方法适用于当前单层住宅，是保守的屏幕矩形重叠判断；可能隐藏房间边缘附近并未精确挡住人物的叶簇，没有声称解决任意建筑和所有场景遮挡。树冠为立即隐藏/恢复，没有透明渐变，也不影响僵尸视线或存档数据。

住宅端到端测试继续使用实际移动/交互输入，补充检查反向镜头确实收起部分前景树冠、仍保留背景树冠，出屋全部恢复，原碰撞层不变。

另补充22:00灯光夹具：走进住宅后明确设置测试时间，拍摄开灯图；用真实L键关灯、保存、继续，再拍摄关灯图并核对灯光状态和时间保留。随后恢复测试时间继续原来的卧室/厨房行走、搜刮、旋转和出屋验证。两张夜景仅验证夜间渲染与存读档，不代表从白天玩到夜间；真实跨日仍由独立睡眠测试验证。本轮没有改变灯功率、电力消耗、夜间视线或生存规则。

运行命令与环境沿用 [室内与镜头报告](interior-camera-pass.md)。完整测试日志：`work/foliage-final-checks.log`；图片：`work/house-night-lit-fixture.png`、`work/house-night-dark-fixture.png`、`work/house-reverse.png`。Blender源文件和19份GLB复用上轮成果，没有重新生成模型；生产存档与导出由测试指纹保护。
