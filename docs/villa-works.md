# 别墅工事 V1：院子门、别墅大门与泳池供水

把「出门搬料 → 回据点施工」的闭环接在别墅上。三处工事都不是菜单里的抽象升级，而是世界里真实存在的东西：两扇能开关、能被僵尸撞坏的门，和一片会真的蓄水的泳池。

## 一、世界观与位置

| 工事 | 位置（世界坐标） | 尺寸 | 结果 |
| --- | --- | --- | --- |
| 院子门 `villa_gate` | (106.1, 0, −2.5) | 跨 4.6m × 高 2.2m × 厚 0.24m | 院墙车道上挂一扇铁艺双开门，装上后院子能封起来 |
| 别墅大门 `villa_door` | (112.85, 0, −17.5) | 跨 1.3m × 高 2.1m × 厚 0.16m | 别墅正面原本敞着的 1.3m 门洞装上一扇木门 |
| 泳池供水 `villa_water` | 池体 (123.3, ·, −10.8)，矩形 7.4 × 4.9 | 水面 y = 0.34 | 接上市政水管后泳池注水，每天可取 3 份水 |

院子门与别墅大门都取院墙/门洞的实际开口尺寸，不是"差不多放一个模型"：院墙碰撞在本地坐标 −10.2…−5.6 之间留出的正是 4.6m 车道口，别墅正面墙在 −1.8…−0.5 之间留出的正是 1.3m 门洞。

别墅据点范围同时扩到整块宅地（`97.9, −26.6, 32.2, 24.2`），院子、泳池与屋内同属 `villa_07`，站院子里也算在据点内。

配方按"一趟搬得动"设计（背包 5kg）：

- 装院子门：铁艺院门×1 + 废金属×1 + 锤子 = 4.7kg，40 分钟。
- 装别墅大门：木板×2 + 废金属×1 + 锤子 = 3.7kg，30 分钟。
- 接泳池供水：管线×2 + 五金件×2 + 锤子 = 4.5kg，60 分钟。

## 三、施工与使用

配方数据在 `data/crafting.json`，目标类型是新的 `site`：

```json
{ "id": "install_villa_gate", "target": "site", "site": "villa_gate",
  "minutes": 40.0, "inputs": {"gate_panel": 1, "metal_scrap": 1}, "tools": ["hammer"] }
```

- 站到工事旁（`interaction_range` 内，按工事占地的矩形算距离）按 **E** 直接开工；没带齐材料会被拒绝并说明缺什么。
- 也可以按 **C** 打开制作面板，靠近别墅时面板顶部会列出三处工事状态，以及对应配方行。
- 施工和修门一样走真实时钟：期间僵尸照常移动，移动/空格停手，材料全额退还一次。
- 完工后 `state.base_works[site] = true`。门类工事同时登记一扇真实门（`state.doors` + `door_health` + `door_level`），耐久从 120 起，之后的开关、被撞、修门、加固全部复用 V1 的门规则。

按键：

- **E**：未完工＝开工；已装的门＝开/关；泳池＝接一瓶水。
- **C**：修门/加固（站到门旁）、烹饪、绷带，以及靠近别墅时的工事配方。
- 关门时若自己站在门洞里，或门洞里有活僵尸，会拒绝并提示。

## 四、僵尸与封院

- 装好且关上的门会把自己的碰撞层设为 1，导航网格按同一开关重新盖章，僵尸不再穿过。
- `zombie.gd` 在街道门之外增加一次 `barrier_at()` 询问：僵尸与记忆中的目标分处门线两侧、且横向在门宽范围内时，把门当作必须破坏的障碍，靠近后按 `door_damage` 规则撞击。
- 门被打坏后自动打开、不再阻挡，需要先用木板修回来（修好的门保持敞开，得手动关）。
- 院子门和别墅大门是两扇独立的门：只装院子门，屋内仍能从正面门洞进出；两扇都装上才是完整的宅院。

## 五、泳池水

- 初始 `state.pool = {day, left: 0}`，泳池是干的，按 E 只会提示"还没有接上市政水管"。
- 供水接通后当天恢复 3 份；每接一瓶消耗 1 份（得到 1 个"饮用水"），跨天自动回满，受背包负重限制。
- 这份配额是为了让"回别墅补水"成为一次有意义的行程，而不是无限水井。

## 六、存档

存档升为 **schema 6**：

- 新增 `base_works`（每处工事一个布尔）与 `pool`（`day` + `left`）。
- `valid()` 校验：工事 id 必须来自世界数据；记为已装的门必须真的有门与耐久记录；未装的工事不能留下孤立门；`pool.left` 不超过容量。
- schema 5 → 6 迁移只补字段；街道存档（没有 `sites`）同样合法，迁移后 `base_works` 为空字典、泳池 0 份。
- 世界修订号 5 → 新容器只补一次，旧库存与门耐久原样保留。

## 七、验收

`tests/test_sites_v1.gd`（`SITES_V1_OK`）覆盖：

1. 新档：工事全部未完成、没有门、泳池干、状态合法；街道场景无工事仍然合法。
2. 搬运：三个容器的物资、两份材料的负重都在 5kg 内。
3. 院子门：远处拒绝 / 门柱旁允许、材料先扣、半程不生效、完工登记门与耐久、`barrier_at` 只在"已装 + 关着 + 两侧跨线"时成立、开门放行、撞坏后失效、修回 120、加固到 170、不能重复安装。
4. 别墅大门：门洞装门、房屋与院子之间成为障碍。
5. 泳池：远处拒绝、接通后 3 份、逐份递减到 0、跨天回满、满负重拒绝。
6. 中断：僵尸靠近时停止并退还管线与五金件。
7. 迁移：schema 5 快照照常读入并补字段；漏记工事、已装无门、水位超容量都被拒绝。
8. 读档：已装的门与泳池水位原样恢复。

`tests/test_sites_scene.gd`（`SITES_SCENE_OK`）在真实场景里再验一遍：三个新容器都能走到并按 E 打开、未装的门不是交互目标、装上后碰撞层与导航格同时变为阻挡、开门后两者同时放行、泳池水面只在接通后出现、按 E 真的接出一瓶水。

`docs/testing.md` 记录完整回归命令；本轮运行通过 `tools/run_checks.py`，包含新加的 `SITES_V1_OK` 与 `SITES_SCENE_OK`。

## 八、当前限制

- 门的开启是整扇旋转 78° 的双开动画，没有逐叶推门、门闩动画或撞击歪斜。
- 院子门与别墅大门只做在别墅这一块宅地上；市集、工厂的门洞尚未接入工事系统。
- 泳池水只能装瓶饮用，没有过滤、灌溉或洗衣机之类的二级用途。
- 工事不可拆回；装错位置只能靠不装来避免。新建自由工事（栅栏、路障）仍未实现。
