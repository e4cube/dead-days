# 生存基调与内容规格 V1（2026-10-31 记录）

用户在 2026-10-30 给出的完整设计意图。这份文件是**目标**，不是现状；现状见下一节对照表。
后续每一轮从"未做"里挑一块，做完把状态改过来，并把实现细节写进各自的增量文档。

## 一句话基调

**开放世界 + 俯视角 + 永久死亡。没有官方结局，目标就是活下去。**
"这就是你死去的故事"——所以每一个机制都要服务于"死得明白"，而不是"活得舒服"。

---

## 一、角色状态

### 五维日常需求

饥饿、口渴、**疲劳、体温、卫生**（现有只有前两项 + 生命 + 体力）。

日常需求要比僵尸更致命：僵尸是可见的、可躲的；需求和伤势是持续的、无声的。

### 精神状态

无聊、不快、压力、孤独、抑郁五个维度，靠读书、听广播、吃东西缓解。
设计含义：独居久了会崩，所以"找到人"本身要有价值；但多人也带来风险。

### 复杂伤势

抓伤 / 撕裂伤 / 咬伤三种：

- **咬伤高概率致命感染**（永久死亡的真正来源）；
- 伤口要**消毒 → 缝合 → 包扎**三步，任意一步缺失就持续流血；
- 不处理会流血致死。

---

## 二、技能与制作

- 开局**选职业**（消防员 / 警察 / 工程师…）+ 正负特质，定制初始能力；
- **数十种技能**：战斗、采集、烹饪、农耕、木工、电工、机械、潜行…；
- 技能靠**读书 + 反复实践**提升，曲线很陡（前期涨得快，后期极慢）；
- **从零建造**：进阶木工 → 加固门窗 → 建围墙 → 造带楼梯的自定义安全屋。

---

## 三、环境与丧尸

- 丧尸的**速度、视力、听力、记忆力、群体行为全部可自定义**（沙盒选项）；
- **真实视野 + 声音系统**：破窗、开枪、发动机噪音都会引尸；
- 推进一段时间后**全城停水停电**，逼你找发电机、接雨水。

---

## 四、战斗

- 近战（棒球棒 / 锅 / 锤 / 砍刀，**爆头最有效**）、枪械、潜行；
- 多尸围攻要考虑体力消耗，**伤口会拖累战斗力**（不是数值惩罚，是操作层面的拖累）。

---

## 五、长期生存循环

**活过一个月才是真正的开始。**

- 农耕、钓鱼、狩猎陷阱、畜牧 → 食物可持续；
- 食物保存：烘干 / 烟熏 / 地窖；
- 技能书、电视 / VHS 节目刷经验；
- 基地分阶段进化：单间加固 → 多房间带工坊与雨水收集 → 多层防御自洽。

---

## 六、"生存日志"（知识传承）

把"死亡即结束"改成"知识传承"，让积累能留给下一个角色 / 其他玩家。

### 核心循环

1. 用**皮革条 + 线 + 针**（裁缝 1 级）制作空白《生存日志》；
2. 拿书写工具右键日志 → "记录进度"，把当前技能 / 特质 / 配方写进去；
3. 死后找回这本日志，**新角色可以读它取回经验**。

### 日志能存什么

技能（含原版 + 已注册 Mod 经验）、特质、已学配方 / 杂志、存活时长 / 击杀数等数据、自定义笔记。
必须有**"基础线限制"**：把创建角色时的初始加成和后天努力分开，防止白嫖。

### 世界里能捡到的四类日志

| 类型 | 来源 | 特点 |
| --- | --- | --- |
| 磨损日志 | 书架 / 书桌等容器 | 奖励较轻，可能含技能 / 配方 / 特质 |
| 血迹日志 | 搜僵尸尸体 | 奖励更强，但需清洗才可读 |
| 诅咒日志 | 稀有尸体掉落（伪装成血迹） | 开封可能受伤 / 恐慌 / 丢失进度；需高采集或"猫眼"等特质识破 |
| 圣诞日志 | 季节限定 | 含圣诞日志 + 补给物资 |

### 额外机制

- **遗忘槽**：一次性奖励，可移除某个负面特质（而不是学新东西）；
- **衰减与限领**：多人服里世界日志有领取次数上限，奖励全局唯一；
- **完整沙盒选项**：刷新率、经验恢复模式（1:1 / 递减）、诅咒概率、容量全可调；
- **多人支持**：权限控制谁能读 / 领 / 写彼此的日志。

## 八、建议实施顺序

按"每一块都能独立验收、且都服务永久死亡基调"来排：

1. **声音空间 V1（已完成）**——让看不见的东西能听见。
2. **伤势与流血（本轮已完成）**——抓/撕/咬，感染判定，消毒/缝合/包扎，流血致死。永久死亡的第一个真实来源。
3. **五维需求 + 精神**——把"活着"变成日常压力，让读书/广播/吃东西有意义。
4. **职业 + 特质 + 技能**——给每个角色一个不同的开局与成长曲线。
5. **从零建造 + 停水停电**——把据点从"借用房子"变成"自己造的家"。
6. **农耕 / 保存 / 畜牧**——真正的长期循环（活过一个月）。
7. **生存日志传承**——把死亡从"删除存档"改成"留下东西"。

多人权限、沙盒选项面板放在多人功能前后再定，取决于是否真的做联机。
