# 末日生存日志 · Dead Days

俯视角 **2.5D 等距**僵尸生存 + 生存日志 单机游戏（Python + Pygame）。

灵感来自《僵尸毁灭工程》：在被尸群占领的小镇里搜刮求生——
但核心不是活下去，而是**把每一天写下来**。游戏会自动记录你的经历
（受伤、击杀、搜刮、睡眠、濒死……），每天黎明自动写一篇日记；
你也可以随时按 `J` 亲手写下带心情标签的条目。死亡时会生成「终章」，
整本日志可一键导出为 Markdown。

## 画面（v0.3 2.5D 等距版）

- 等距菱形地块 + 带高度墙体（三面受光）、立式小人、深度排序遮挡
- 昼夜循环：夜晚全场景压暗，玩家周围渐变光圈 + 暖色微光
- 程序化贴图：草地/木地板/砖墙/道路/动态水波/树冠，无外部资源

## 运行

```bash
pip install -r requirements.txt
python main.py
```

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Shift | 奔跑（耗精力，噪音更大） |
| 空格 | 攻击 |
| E | 搜刮容器 / 喝湖水 |
| 1 / 2 / 3 | 吃罐头 / 喝水 / 用绷带 |
| T | 睡觉到黎明（附近有僵尸无法入睡，可能被夜袭） |
| J | 打开/合上生存日志 |
| Esc | 存档并回主菜单 |

日志界面：直接打字输入，`←/→` 切换心情标签，`Enter` 写下，
滚轮翻页，`F5` 导出 Markdown（存到 `exports/`）。

## 玩法系统

- **四维生存**：生命 / 饱食 / 水分 / 精力，饥渴归零会持续掉血，吃饱喝足缓慢回血
- **昼夜循环**：一天 = 现实 6 分钟；夜晚视野变差，僵尸更凶、跑得更快
- **僵尸生态**：游荡—索敌—追击，数量随天数增加；奔跑会吸引更多注意
- **搜刮**：随机生成的小镇（14 栋房屋 + 道路网 + 树林 + 湖泊），容器里有罐头、水、绷带，运气好的能捡到棒球棍、砍刀
- **存档**：自动存档（黎明/睡觉/退出）+ 读档继续，死亡即删档（Roguelike）
- **自检**：`python main.py --selftest` 可无头跑完整流程冒烟测试
